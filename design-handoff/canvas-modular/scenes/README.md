# 캔버스 모듈화 — 멘탈 모델 확정 장면 (CD → writer)

> 인풋: `design-handoff/canvas-modular/CONTEXT-FOR-CD.md`(방향 1 팔레트 + 작업면). **풀 번들이 아닙니다.** 장면 M0–M3을 사용자가 확정하면 풀 번들로 넘어갑니다.
> 비주얼: `canvas-modular-scenes.dc.html`(같은 폴더의 `support.js`가 있어야 열림). 레인 내부는 `widget-chain/v3/README.md`를 그대로 따릅니다.

## 장면
- **M0a** 팔레트 + 빈 작업면 · **M0b** 레인이 하나 있을 때 · **M1** 팔레트 → 레인 드래그 · **M2** 레인 + 단독 인스턴스(Phase 2 미리보기) · **M3** 팔레트 상태 9종 + 접힌 레일

## 핵심 결정
| 결정 | 고른 것 | 버린 것 |
|---|---|---|
| 팔레트 위치 | **왼쪽 고정 레일 240**(캔버스 transform 밖). 풀뷰 사이드바와 자리·폭이 같음 | 하단 독 · 플로팅 패널 · 상단 바 |
| 모듈 타일 | **가로 행 216×64** — 톤 타일 36 + 이름 + 둘째 줄(메타 ↔ 상태) + 그립 | 정사각 아이콘 그리드(이름 잘림) · 미니 카드(셸로 오인) |
| 제스처 | **끌기 = 조립 · 누르기 = 그 위젯이 있는 곳으로**(작업면에 있으면 이동, 없으면 풀뷰). Phase 1·2 모두 같은 뜻 | 빈 곳에 놓으면 새 체인(Phase 2에서 뜻이 바뀜) |
| 드래그 | 고스트 = **타일 자체**(body 포털). 놓는 순간 슬롯이 카드로 교체. **좌표 기반 판정** | 카드 크기로 부풀리기 · HTML5 dragenter/leave(LEARNINGS §2-2) |
| 단독 인스턴스(P2) | **셸 그대로 + 카드 위 이름표.** 치우기 = 팔레트로 끌어다 놓기 | 길이 1 레인(방향 2) · 카드에 ✕ |
| 미지원 위젯 | **흐리지 않음.** 체인 지원 3종에만 "체인" 표시 | 미지원 4종 회색 처리 |

## 열린 질문 답 (브리프 §4)
1. **발행:** 그리드 좌표는 퇴역합니다. 발행 = 팔레트 노출 on/off + 순서이고, 미발행 위젯은 숨깁니다.
2. **Navigator:** 위젯 단위 상태는 팔레트가 맡으므로 중복입니다. 팔레트 타일에서 펼치는 작업 목록으로 통합하기를 권장합니다. 다만 Navigator가 위젯 단위가 아닌 정보도 보여주고 있다면 통합 대신 축소해야 하니 확인이 필요합니다.
3. **Phase 1 단독 실행:** 타일을 누르면 풀뷰로 바로 갑니다. 빈 작업면에 놓으면 받지 않고 타일이 돌아갑니다.
4. **좁은 뷰포트:** 1280 미만이면 72 폭 레일로 접힙니다. 768 미만이면 하단 시트로 바뀌고, 드래그 대신 탭으로 "열기 / 체인에 추가"를 고릅니다.

## v3에서 고친 것 1건
v3의 "+ 새 체인"은 캔버스 좌표(56)로 그려져 있었습니다. 이 버튼은 화면에 고정되는 요소라 **화면 px 40**으로 고쳤습니다(LEARNINGS §3-1).

## 확인 필요
- 현행 위젯은 9종인데 확인된 7종만 그렸습니다. 나머지 2종도 같은 타일 문법입니다.
- 타일 아이콘은 자리표시입니다. 실제로는 `iconography-duotone` 세트로 교체합니다. 파스텔 타일 안에 놓이므로 채움은 흰색입니다(SSOT §A5).
- 신규 토큰 후보: `--palette-w 240`, `--palette-tile-h 64`(proposed-token).
