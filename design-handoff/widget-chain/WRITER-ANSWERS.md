| 1 | `steps[].fileCount?` | **채택 (옵셔널 prop)** | 어댑터(C)가 kick 시점에 파일 수를 steps 에 기록. 파일럿 체인에선 전사 md 1개 → 항상 1 — "💎25 (파일 1 × 25)" 분해 표시 가능. 값 없으면 cost 합계만(스펙 폴백 그대로) |

| 3 | error 시 크레딧 환불 여부 | **문장 삭제** | 보장 불가 — 차감 시점이 단계별로 다름(전사=완료 시 차감이라 실패 시 미차감 참 / 인제스트=선차감이라 실패 시 이미 차감). 단계 불문 참인 문장이 아니므로 B6 에서 "크레딧은 차감되지 않았습니다" 제거, `steps[i].error` 사유만 표시 |
| 4 | cancelled 시 남은 steps | **표시 매핑 승인** | 계약상 pending 으로 남음 → 프레젠테이션이 B9 에서 skipped 로 매핑(CD 안 그대로). 서버 상태는 불변 |
| 5 | 프로젝트 피커 데이터 | **컨테이너 소유 확정** | 기존 interviews 프로젝트 목록 소스 재사용(신규 API 금지 — 워커가 기존 훅/라우트 확인 후 배선). "+ 새 프로젝트" 생성도 기존 생성 경로 재사용 |
