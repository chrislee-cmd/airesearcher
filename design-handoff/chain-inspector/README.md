# Handoff: 체인 인스펙터 — 요약 카드 + 오른쪽 인스펙터

## Overview
체인 레인 안의 위젯 카드를 **604×900 설정 폼**에서 **240×300 읽기 전용 요약 카드**로 바꿉니다. 세부 설정은 카드를 누르면 열리는 **오른쪽 인스펙터(400)**로 옮깁니다. 카드가 작아지므로 1440 뷰포트에서 3단계 체인 전체가 **줌 100%**로 한 화면에 읽힙니다.

- **바뀌는 것:** 레인 카드 렌더링, 레인 헤더 치수, 인스펙터 패널 신설, 레인 안 설정 편집 위치.
- **안 바뀌는 것:** 체인 계약(`ChainView`), 세그먼트·캡슐 문법(v3), 팔레트(canvas-modular Phase 1), 상태 어휘, 풀뷰, 체인 밖 단독 위젯 카드(604×900 그대로).

## About the Design Files
`chain-inspector-scenes.dc.html`은 **HTML로 만든 디자인 레퍼런스**입니다. 그대로 복사하는 프로덕션 코드가 아니고, airesearcher 레포의 기존 환경(Next.js + React + Tailwind, Soft Identity 토큰)에서 다시 구현하는 것이 작업입니다. 파일은 같은 폴더의 `support.js`가 있어야 열립니다(런타임일 뿐 포팅 대상 아님).

## Fidelity
**High-fidelity.** 프레임은 모두 실치수입니다. 시각 값은 Soft Identity 토큰을 따릅니다(`tokens.css` — `design_handoff_soft_identity` 참조). 세그먼트의 선 색과 굵기는 근사치이고 **v3 세그먼트 SSOT가 우선**합니다.

## 1. 요약 카드 (I1)

### 1.1 고정 치수
- 240 × 300 고정 · radius 14 · border 1 `--line` · `--sh-card` · bg `--surface`.
- **상태가 바뀌어도 높이는 300**입니다. 세그먼트 가운데선(y 150)이 흔들리지 않도록 하기 위해서입니다.

### 1.2 구조 (위에서 아래로)
| 영역 | 값 |
|---|---|
| 헤더 | pad 14/14/0 · gap 10 · 톤 타일 30(radius 8, 아이콘 16 흰 채움 + ink 1.8) · 이름 13.5/700 한 줄 말줄임 · 아래 단계 mono 10.5 `--faint`("3단계") |
| 상태 배지 | pad 10/14/0 · 시그널 배지(테두리 없음, 점 6, 11/600) |
| 본문 | flex 1 · pad 12/14 · gap 10 · 최대 3행 |
| 푸터 | 높이 44 · border-t 1 `--hair` · pad 0/14 · 왼쪽 mono 11 `--mute` · 오른쪽 액션 |

### 1.3 상태 4종
| key | 테두리·면 | 배지 | 본문 | 푸터 |
|---|---|---|---|---|
| unset | **1.5 dashed `#c4c1c9`** · bg `#fcfcfd` · 그림자 없음 | warn "설정 필요" | "필수 설정 n개가 남았어요"(12.5/600) + 남은 항목 체크리스트(빈 원 12, 최대 3) | 예상 비용 · **주 버튼 "설정하기"**(ink pill 28) |
| ready | 기본 | idle "준비됨" | 요약 행 최대 3 + "외 n개 설정"(11.5 `--mute`) | 예상 비용 · 텍스트 "편집" |
| running | 기본 | run "진행 중"(점 깜빡임) | 진행 바 4px(`--run-track`/`--run-dot`) + 현재 작업 한 줄 12 · 요약 행 2개 opacity .55 | 남은 시간 |
| done | 기본 | ok "완료" | **결과 요약** 3행(산출물 · 수량) | 완료 시각 · 링크 "결과 보기 ↗" 12/600 |

**선택됨(인스펙터가 이 카드를 편집 중일 때):** 그림자를 `0 0 0 2px ink, 0 0 0 6px {위젯 톤}`으로 바꾸고, 헤더 오른쪽에 "편집 중" ink pill(10.5/600)을 붙입니다. 4상태 모두에 겹쳐 쓸 수 있습니다.

### 1.4 요약 행
- 레이블 10.5 `--faint` 위, 값 13/600 아래. 행 간격 10.
- 값은 한 줄 말줄임이고 레이블은 6자 이내입니다.
- 4번째 항목부터는 "외 n개 설정"으로 접습니다.

### 1.5 히트 영역
- 카드 전체가 버튼(`role="button"`, `aria-pressed`=선택 여부)이고, 누르면 인스펙터가 열립니다.
- "설정하기"와 "결과 보기 ↗"만 별도 타깃입니다. "설정하기" = 인스펙터 열기, "결과 보기" = 기존 풀뷰 열기.
- 카드 안에 입력 필드, 토글, 실행 버튼을 두지 않습니다.

## 2. 레인 (I0)

| 요소 | 현행(v3) | 변경 |
|---|---|---|
| 헤더 높이 | 72 | **52** |
| 제목 | 22 | **15**(Bricolage 700) |
| 상태 문구 | 18 | **12**(mono 700 + 점 6) |
| 링크 타일 | 40 | **28** |
| 본문 패딩 | 32/40 | **28/24** |
| 헤더 sticky | — | **sticky-left**: 레인을 팬해 헤더 왼쪽이 화면 밖으로 나가면, 헤더 내용이 보이는 창의 왼쪽 끝에 붙어 따라옴 |
| 카드 | 604×900 | 240×300 |
| 세그먼트 | 폭 96 · 가운데선 = 카드 높이/2 | 그대로(가운데선 y 150) |

레인 폭 = 패딩 24×2 + 카드 240×n + 세그먼트 96×n + 산출물 112. 3단계 기준 1168.

**줌:** 기본 fit 상한을 100%로 둡니다. 1440에서 3단계는 100%로 들어가고, 축소는 4단계 이상 체인에서만 쓰입니다. 줌 기능 자체의 퇴역은 이번 범위가 아닙니다.

## 3. 미설정과 실행 차단 (I0)
같은 사실을 세 곳이 함께 말합니다. 상태 어휘는 새로 만들지 않습니다.
1. **카드:** unset 상태.
2. **앞 세그먼트:** v3 차단 표현. 앞 절반은 회색 실선, 뒤 절반은 warn 점선, 화살촉은 warn.
3. **레인 헤더:** 상태 문구를 warn 색으로 "n단계 설정 필요 · 아직 시작할 수 없어요".

**런타임:**
- 체인은 세션 종료로 시작하므로 시작을 막을 시점이 없습니다.
- 앞 단계까지는 정상으로 진행합니다. 미설정 단계 앞에서는 **paused(사유: 설정 필요)**로 멈춥니다.
- 사용자가 필수 항목을 채우면 그 단계부터 재개합니다. 재개 방식(자동 또는 승인 모드 규칙)은 기존 paused 처리와 같습니다.

## 4. 인스펙터 (I2 · I3)

### 4.1 열림 방식 — 밀어내기
- 폭 400(좁은 화면 규칙은 §6). 오른쪽 고정 · 높이 뷰포트 전체 · bg `--surface` · border-l 1 `--hair`. **캔버스 transform 밖**에 둡니다.
- 열리면 **캔버스 뷰포트가 400 좁아집니다.** 레인의 캔버스 좌표는 그대로이고, 보이는 창만 줄어듭니다.
- 선택 카드가 줄어든 창 밖이거나 가려질 때만 240ms ease-out으로 팬해 창 가운데로 옮깁니다. 줌은 바꾸지 않습니다.
- 열림·닫힘 전환은 폭 0↔400, 200ms ease-out입니다. reduced-motion이면 즉시 바뀝니다.
- 인스펙터가 레인을 덮는 일은 없습니다(오버레이 금지).

### 4.2 헤더 (64)
- pad 0/14/0/20 · border-b `--hair`.
- 톤 타일 32 → eyebrow mono 10.5 `--faint`("체인 1 · 2 / 3") + 제목 15/700 → ‹ › 원형 30(1px `--line`. 첫·마지막 단계에서는 해당 쪽 글자를 `--disabled-fg`로) → 닫기 ✕ 32(테두리 없음, 1.8 스트로크 `--mute` — 닫기 버튼 SSOT 규칙).

### 4.3 상태 줄
pad 10/20 · border-b `--hair` · 시그널 배지 + mono 11 비용 또는 남은 시간.

### 4.4 본문 — 설정 형식
| 요소 | 값 |
|---|---|
| 패널 패딩 | 20 · 세로 스크롤 |
| 섹션 | 제목 13/700 + 설명 12 `--mute` · **섹션 간격 26** |
| 필드 | 라벨 12.5/600 `--ink-2` 위 · 필수 표시("필수" 10.5 `--faint`)는 라벨 옆, 힌트(11 `--faint`)는 라벨 줄 오른쪽 · **필드 간격 14** |
| 입력 · select | 전폭(400 → 360 / 360 → 320) · 높이 38 · radius 10 · 1px `--line` · focus = border ink + `--focus-ring` |
| textarea | min-height 78 · pad 10/12 · 13/1.6 |
| 세그먼트 | `--fill` 트랙 pad 3 · 선택 = 흰 칩 + `0 1px 2px ink/8` · 옵션 4개 이상이면 select로 |
| 칩(다중 선택) | pill pad 5/12 12/600 · 선택 ink 면 흰 글자 · 미선택 `--fill` |
| 토글 | 라벨(+힌트) 왼쪽, 스위치 36×20 오른쪽 한 줄 · on ink / off `#d6d4da` · 노브 16 |
| 순서 목록 | 행 38 · radius 9 · 1px `--hair` · mono 번호 + 텍스트 + ⋮(재정렬 핸들) · "+ 항목 추가" 텍스트 버튼 |
| **앞 단계 입력** | 편집 필드가 아닌 **읽기 전용 행**입니다. `--surface-2` 면 · 1px `--hair` · radius 10 · 앞 단계 톤 타일 26 + 값 12.5/600 + 설명 11 + "앞 단계" 칩(`--fill`) |

### 4.5 저장
- **자동 저장**이라 저장·되돌리기 버튼이 없습니다.
- 값이 바뀌면 즉시 카드 요약에 반영합니다(낙관적 반영). 서버 저장은 debounce 400ms입니다.
- 실패하면 하단 진행도 자리에 err 문구를 띄우고 마지막 값을 유지합니다(재시도 버튼 하나).
- 되돌리기는 필드 단위 Cmd+Z(브라우저 기본)입니다.

### 4.6 하단 (pad 14/20 · border-t `--hair`)
- **왼쪽:** 필수 진행도("필수 2 / 3", 12.5/600 + 점 6) + mono 10.5 저장 상태("자동 저장됨 · 방금"). 필수가 남았으면 warn, 모두 채웠으면 ok.
- **오른쪽:** 마지막 단계가 아니면 주 버튼 "다음 단계 →"(‹ ›와 같은 동작), 마지막 단계면 보조 버튼 "닫기". 필수가 남아도 다음 단계로 가는 것은 막지 않습니다.

### 4.7 열기 · 닫기 · 이동
- **열기:** 카드 누르기, "설정하기" 버튼.
- **닫기:** ✕ · Esc · 같은 카드 다시 누르기 · 빈 작업면 누르기.
- **이동:** ‹ › · "다음 단계 →" · 다른 카드 누르기. 선택과 팬이 함께 옮겨갑니다(필요할 때만 팬).
- **포커스:** 열리면 인스펙터 첫 편집 필드로, 닫히면 원래 카드로 돌아갑니다. 인스펙터는 `role="complementary"` + `aria-label="체인 1 · 2단계 설정"`이고, 모달이 아니므로 포커스 트랩을 걸지 않습니다.
- **카드와의 연결:** 선택 링 + "편집 중" pill + 인스펙터 헤더의 같은 톤 타일과 단계 번호로 보여줍니다. **카드와 패널 사이 커넥터 선은 쓰지 않습니다.**

## 5. 잠금 (I3b)
- **실행 중·완료 단계:** 인스펙터가 읽기 전용입니다.
  - 맨 위 안내 박스(`--run-bg` · radius 10 · 12.5 `--run-fg`): "실행 중에는 설정을 바꿀 수 없어요. 바꾸려면 체인을 종료하세요."
  - 컨트롤: 면 `--fill`, 글자 `--faint`, 테두리 없음. 토글 on은 `#9a96a1`, off는 `#e7e5ea`. 선택된 세그먼트·칩은 `#e9e7ec` / `#c4c1c9`. **래퍼 opacity는 쓰지 않습니다.**
  - 하단 왼쪽: run 점 + "실행 중 · 설정 잠김" · 시작 시각.
  - 하단 오른쪽: 보조 버튼 "진행 보기 ↗"(완료면 "결과 보기 ↗") → 기존 풀뷰.
- **대기 단계**(아직 차례가 아님)는 실행 중에도 편집할 수 있고, 그 단계가 시작되는 순간 잠깁니다. 편집 중에 잠기면 안내 박스가 160ms 페이드인으로 나타나고 입력 포커스가 풀립니다.

## 7. 산출물
- 카드의 "결과 보기 ↗", 인스펙터 하단(완료 단계), 체인 끝 산출물 노드(완료 시)가 모두 **기존 풀뷰**로 갑니다.
- 인스펙터에 결과 탭은 두지 않습니다.

## 8. writer 정의가 필요한 것 (구현 전 · 위젯별)
1. **요약 3항목:** 카드에 보일 레이블·값 3개와 순서(레이블 6자 이내). 완료 상태의 결과 요약 3개도 함께.
2. **필수 항목:** unset 체크리스트와 인스펙터 진행도의 근거.
3. **인스펙터 필드 목록:** 기존 셋업 항목을 §4.4 형식(섹션 · 필드 종류)에 옮겨 담기.

파일럿 3종(인터뷰 어시스턴트 · 전사록 생성기 · 인터뷰 결과 생성기)은 컴프의 값이 **제안**입니다. 전사록 생성기와 인터뷰 결과 생성기의 인스펙터는 I2·I3에 전체를 그렸습니다. writer가 확정하기 전에는 하드코딩하지 말고, 위젯 메타(registry)에 `summaryFields` · `requiredFields` · `inspectorSchema`로 선언해 공용 렌더러가 읽게 합니다.

## 9. 레이어 · 판정 (LEARNINGS)
- 인스펙터와 팔레트는 캔버스 transform 밖 형제입니다. `[data-canvas-body]` cascade가 닿지 않습니다.
- 카드 선택 링은 포털된 카드 노드에 줍니다. 그리드 래퍼에 주면 안 됩니다(§8-3).
- 카드 hover와 누르기는 기하 판정입니다. enter/leave 이벤트는 쓰지 않습니다(§2-2).
- 저줌(< FOCUS_THRESHOLD)에서 click-to-focus 오버레이가 깔려 있으면, 첫 클릭은 포커스(줌 인)이고 두 번째 클릭부터 인스펙터를 엽니다. 이건 기존 규칙과 같습니다.
